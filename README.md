This repository contains the Mathematica notebook (Analyses.nb) used to generate the numerical results presented in:

Maisonneuve, L. & Lehmann, L. When to learn from olders or peers: accessibility–knowledge trade-offs explain diversity in age-biased social learning. bioRxiv https://doi.org/10.64898/2026.06.16.732531

Open the notebook in Mathematica and evaluate the cells to reproduce the analyses.
